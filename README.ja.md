# kurocat-customeowze

KuroCat をベースにした非公式 Fork です。MCP 経由で独自の猫の画像素材を取り込み、顔・毛色・画風・頭身を調整できます。原版のキー入力・マウス・まばたき動作を利用します。

現在は実験的なソースコード版です。この Fork のインストーラーはまだありません。画像生成は AI クライアント側で行います。Windows / Linux と各 AI クライアントとの接続は未検証です。
